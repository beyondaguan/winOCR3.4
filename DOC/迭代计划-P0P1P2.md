## P0：立即修复（阻塞测试 / 本地开发环境"串味"）

### P0-1：废弃 `CI=1` → `WINOCR_CI` + pytest headless 参数

**现状问题**：
- `test_gui_smoke.py` 和 `test_project_bar.py` 各有一份 `_has_display()`，都检查 `os.environ.get("CI")`
- `CI=1` 是通用环境变量，在本机开发时残留（如从 CI 日志复制命令），导致 GUI 测试全跳过
- CI workflow `.github/workflows/ci.yml` 也设 `CI: "1"`

**改动清单**：

| 文件 | 改动 |
|------|------|
| `tests/test_gui_smoke.py` | `_has_display()` 中 `os.environ.get("CI")` → `os.environ.get("WINOCR_CI")` |
| `tests/test_project_bar.py` | 同上；同时抽取 `_has_display()` 到公共 `tests/conftest.py` 消除重复 |
| `tests/conftest.py`（新增） | 统一 `_has_display()` + `pytest_addoption("--headless-gui")` 注册 |
| `.github/workflows/ci.yml` | `env: CI: "1"` → `env: WINOCR_CI: "1"` |

**pytest 自定义参数方案**：
```python
# tests/conftest.py
import pytest, os, tkinter as tk

def pytest_addoption(parser):
    parser.addoption("--headless-gui", action="store_true",
                     help="跳过所有需要 Tk 显示环境的 GUI 测试")

def has_display() -> bool:
    if os.environ.get("WINOCR_CI") or "--headless-gui" in os.sys.argv:
        return False
    try:
        r = tk.Tk(); r.destroy(); return True
    except Exception:
        return False
```

**验证**：本机 `WINOCR_CI=""` 后 GUI 测试不再跳过（排除 mainloop 阻塞项另算）。

### P0-2：`_FakeWindow` 接口漂移修复

**现状问题**：
- `test_selection_translate_busy.py::_FakeWindow` 是手写 Mock，与真实 `MainWindow` 接口不同步
- 失败测试 `test_capture_and_translate_uses_latest_text` 报 `AttributeError: '_FakeWindow' object has no attribute 'sticker_original'`
- **根因不是接口漂移，而是竞态**：`_done` 回调先 `_release_busy()`（清 `_busy`）再 `post(show_sticker)`，测试的 `while _busy.is_set()` 在两者之间退出，此时 `sticker_original` 尚未设置

**改动方案**：

1. **`_FakeWindow.__init__` 初始化所有属性**（防御竞态）：
```python
def __init__(self):
    self.busy = False
    self.status_text = ""
    self.sticker_original = ""      # ← 新增：初始化，避免竞态时 AttributeError
    self.sticker_translation = ""   # ← 新增
```

2. **测试 wait 条件同步修复**（等待真正关心的条件，而非 busy 释放）：
```python
# test_capture_and_translate_uses_latest_text
deadline = time.time() + 5
while time.time() < deadline:
    if (not ui._busy.is_set()
            and ui.window.sticker_original == "刚刚高亮的新文字"):
        break
    time.sleep(0.05)
```

3. **PEP 544 Protocol（防漂移）**：
```python
# tests/protocol.py（或 conftest.py 内）
from typing import Protocol

class WindowProtocol(Protocol):
    def set_busy(self, b: bool) -> None: ...
    def set_status(self, t: str) -> None: ...
    def get_selected_text(self) -> str: ...
    def get_original(self) -> str: ...
    def get_translation(self) -> str: ...
    def show_sticker(self, original: str, translation: str = "") -> None: ...
    def refresh_engine_label(self) -> None: ...
    # ... TkUi 调用 window 的全部方法
```
`_FakeWindow` 声明 `_FakeWindow: WindowProtocol`，mypy 静态检查捕获漂移。
运行时不引入开销（Protocol 是 ABC 的轻量替代）。

**验证**：`test_selection_translate_busy.py` 全部 5 项通过。

## P1：近期补强（关键测试覆盖）

### P1-1：pystray 真集成测试（轮询 wait 模式）

**现状问题**：当前只能 mock 验证 `tray.stop()` 调 `icon.stop()` + `thread.join()`，无法验证真实 pystray 线程退出。

**落地难点**：pystray 在 Windows 上依赖消息循环，`stop()` 后线程退出有微小延迟。

**测试方案**（用户建议的轮询模式）：
```python
# tests/test_tray_integration.py
import time, threading, pytest

pystray = pytest.importorskip("pystray")
from PIL import Image

@pytest.fixture
def tray():
    from winocr.ui.tk.tray import TrayIcon
    img = Image.new("RGB", (64, 64), "#1677ff")
    t = TrayIcon(show_cb=lambda: None, quit_cb=lambda: None)
    assert t.start() is True
    yield t
    t.stop()

def test_tray_thread_is_daemon(tray):
    """patch 后的线程必须是 daemon（不会拖住进程退出）。"""
    assert tray._thread is not None
    assert tray._thread.daemon is True

def test_tray_stop_joins_thread(tray):
    """stop() 后线程在 2s 内真正退出（轮询等待，不直接 assert）。"""
    tray.stop()
    assert tray._thread is None  # stop() 清空了引用
    # 但我们记得原线程对象... 改为：stop 前先记引用
```

**修正**：`stop()` 清空了 `self._thread`，所以需要在 stop 前记引用：
```python
def test_tray_stop_joins_thread(tray):
    thread = tray._thread  # stop 前记引用
    assert thread is not None and thread.is_alive()
    tray.stop()
    # 轮询等待线程退出（给 Windows 消息循环缓冲时间）
    for _ in range(20):
        if not thread.is_alive():
            break
        time.sleep(0.1)
    assert not thread.is_alive(), "托盘线程在 2s 内未退出"
```

**skipif 无显示环境**：真集成测试需要 pystray 能创建图标（需要桌面会话），CI 环境跳过。

### P1-2：GUI mainloop 测试改为带超时 + 自动退出

**现状问题**：`test_event_bus_updates_ui_from_worker_thread` 和 `test_post_drains_via_pump_in_fifo_order` 调 `root.mainloop()`，在非交互环境会阻塞。

**改动**：已有 `root.after(900/1200, _check)` + `_check` 里 `root.quit()`，但超时时间太长。改为：
```python

# 加 pytest 超时保护
```
或用 `pytest-timeout`（需加到 dev 依赖）标记 `@pytest.mark.timeout(10)`。

## P2：中期工程化

### P2-1：CI 加 PyInstaller 构建步骤 + exe 冒烟

**现状**：`.github/workflows/ci.yml` 只跑 pytest，不验证打包。

**新增 job**：
```yaml
  build:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install full + dev
        run: pip install -e ".[full,dev]"
      - name: Build (PyInstaller onedir)
        run: |
          .venv\Scripts\python.exe -m PyInstaller packaging/winocr.spec --clean --noconfirm
      - name: Smoke test built exe
        run: |
          dist\WinOCR\WinOCR.exe --version
          dist\WinOCR\WinOCR.exe doctor
```

**关键验证点**：capsules 动态导入在冻结环境中不失效（pkgutil 发现 `.pyc` 形态）。
