WinOCR 3.4 多元化包容性视觉优化

从「单一医生用户」到「全球多元群体」的视觉设计升级

WCAG 2.1 AA 合规 · 6大改进维度 · 12项具体优化

设计哲学转变

原设计隐含假设用户为「有医学背景的中年男性、中文母语、视力正常」。新方案基于 WCAG 2.1 AA 标准，将用户群体扩展至全球多元用户。

6大改进维度

🎨

色彩系统 — 从单一强调到语义化多元

✗ 仅 #ff6b2c 琥珀橙一种强调色 + 仅暗色主题
✓ 6色语义系统（橙/蓝/紫/翠/琥珀/青）+ 暗色/浅色/高对比度三主题
👥 色盲用户 · 光敏感用户 · 老年用户 · 多文化用户
🔤

字体系统 — 阅读障碍友好 & 中文深度优化

✗ IBM Plex Sans 无特殊优化，Noto Sans SC 仅为后备
✓ 可选 OpenDyslexic（加粗底部设计）+ 霞鹜文楷中文展示字
👥 阅读障碍用户(~15%) · 中文用户(~18亿) · 注意力缺陷用户
🔣

图标系统 — 从 Emoji 到 SVG 语义图标

✗ Emoji（📸📋💬⚙）跨平台渲染不一致，屏幕阅读器无法识别
✓ 统一 SVG 图标库 + 文字标签双重编码，完整 aria-label
👥 屏幕阅读器用户 · 跨平台用户 · 认知障碍用户
👆

交互目标 & 动效 — 44px 触摸目标 + 减少动效

✗ 30-32px 按钮，仅 @media prefers-reduced-motion
✓ 最小 44×44px + 运行时全局一键关闭动效
👥 运动障碍用户 · 前庭系统敏感用户 · 老年用户
🌍

多语言 & RTL — 从中文优先到全球包容

✗ 仅 LTR 布局，固定 EN→ZH 翻译方向
✓ dir="rtl" 自动翻转 + 任意语言对翻译
👥 阿语用户(~4亿) · 希伯来语用户(~900万) · 多语言用户
🖼

图像替代文本 — 屏幕阅读器友好

✗ 信息性 alt 缺失，装饰图标被冗余朗读
✓ 有意义 alt 文本 + aria-hidden 标记装饰图标
👥 屏幕阅读器用户 · 盲人/低视力用户

总结 · 包容性设计提升

✓ 从 1种主题 到 3种主题（暗色/浅色/高对比度）

✓ 从 1种强调色 到 6色语义系统

✓ 从 30px 触摸目标 到 44px WCAG AAA 合规

✓ 从 仅支持中文→英文 到 任意语言对 + RTL 支持

✓ 从 Emoji 图标 到 SVG 语义图标 + 完整 ARIA

✓ 覆盖用户群体从 ~100万中文医生 到 全球多元用户
