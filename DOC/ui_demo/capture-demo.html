交互设计决策

遮罩层
背景压暗至 rgba(0,0,0,.6)，保留桌面元素的可识别性。

选区框使用 2px #ff6b2c 边框 + 8% 透明度填充，确保在任何背景下可见。
选区交互
拖拽绘制矩形，实时显示 宽×高 尺寸标签。

确认后进入扫描阶段，Esc 可随时取消。
扫描反馈
扫描线动画 1.5s 循环，配合琥珀橙辉光。

面板逐字淡入，翻译结果按行依次出现。
结果叠加
OCR 原文面板（左侧，蓝色标签）与翻译结果（右侧，橙色边框）同时展示。

逐词对照悬浮翻译，鼠标悬停原文词汇即可查看对应译文。
划词翻译
非截图模式下，选中任意应用中的文字后按 Ctrl+D，弹出紧凑翻译浮层。

浮层跟随选区位置，自动避让屏幕边缘。
性能要点
遮罩渲染使用 position:fixed + will-change，动画只动 transform 和 opacity。

OCR 工作线程与 UI 完全解耦，通过事件总线传递结果，主线程零阻塞。
鼠标拖拽 绘制选区 Enter 确认 Esc 取消 Ctrl+D 划词翻译
