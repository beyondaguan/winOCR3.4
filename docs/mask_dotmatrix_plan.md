> 项目路径：`D:\Documents\winOCR3.4-master`（`D:\winOCR3.4` 为另一副本，不在此列）

## 0. 背景与现状（已查清，有证据）

- **当前渲染**：`mask_window.py` 的 `_render()` 用**单个 Tk `Text` 控件**承载译文。
  逐行自适应字号（`_fit_font_size`）已解决「字形巨大」问题；但 `Text` 不支持
  「每行任意 y 偏移」，只能靠逐行高度累加排布 → **长文会纵向漂移**，并非逐像素对齐
  OCR 原坐标。
- **OCR 框粒度**：RapidOCR 检测是**行级**（`line_boxes` 每行一个四点框），**无词/字级小框**。
  这是「小框自动框选」可行性的硬约束——更细的框不能靠 OCR 直接给，需自行切分。
- **翻译引擎**：蒙版复用主界面 `TranslateDispatcher`（与发版无关，本方案不改）。

## 1. 目标

1. 蒙版译文**精确到 OCR 原行 y 坐标**回填（消除漂移）。
2. 对每行做**点阵分析（水平投影）**自动切出**字符小框**，译文逐字按原小框栅格节奏回填，
   实现「原位覆盖 + 点阵小框」质感。
3. 维持已有交互：拖拽移动、随拖重译开关、Ctrl+Shift+N 刷新、方向切换、缓存、silent。
4. 投影失败 / 无小框时**回退**到整行均布，绝不崩。

## 2. 架构改动

| 项 | 现状 | 方案 |
|---|---|---|
| 译文承载 | `Text` 控件（`self._tran`） | **`Canvas`（`self._cv`）**，绝对坐标定位 |
| 标题栏 | `pack(side=TOP)` 占顶 | 仍 `pack` 占顶；Canvas `pack` 填满其下区域 |
| 坐标映射 | 无（逐行累加） | canvas 局部坐标 = OCR 图像坐标（0,0=选区左上） |

坐标换算：选区抓取 `ImageGrab.grab(bbox=_orig_bbox)`，图像原点 = 屏幕 `(bx,by)`；
OCR 框坐标即相对该原点。Canvas 置于窗口 `(bx,by)` 且 `pack` 填满 **bar 之下**，
故 `canvas_y = box_y - BAR_H`，`canvas_x = box_x`。译文按 `(box_x, box_y-BAR_H)` 锚定。

> 注：标题栏高 `BAR_H` 会盖住选区最顶一行原文，这是既有设计（bar 兼作拖拽手柄），
> 原/译文顶行均被 bar 覆盖，本方案不移动 bar，仅保证 **bar 以下逐行精确原位**。

## 3. 点阵分析算法（水平投影切小框）

对每行 `box=(x0,y0,x1,y1)`：

1. 从 `_render` 收到的源图 `img` 裁剪该行：`line_img = img.crop((x0,y0,x1,y1))`。
2. 转灰度 → 二值（文字=墨）。对每一**列**累加墨像素数得 `col_ink[]`。
3. 找间隙：列墨数低于 `阈值`（如行高方向墨像素中位数 × 0.3，或相对阈值）且连续 ≥`MIN_GAP` 列的
   区段 = 字符间隙 → 切出 **字符小框** `[x_start, x_end]`（点阵分析 + 小框自动框选）。
4. 计算各小框中心 `cx_k`；若切出 `K≥2` 个小框，记录栅格；否则标记「投影失败」。

复杂度：纯 PIL/NumPy 数组运算，每行 O(宽×高)，百字文档毫秒级，零联网、零额外模型。

## 4. 译文 → 小框 回填映射

设某行译文 `T` 有 `L` 个字符，原行切出 `K` 个小框（中心 `cx_0..cx_{K-1}`，行宽 `[x0,x1]`）。

- **K≥2（有栅格）**：逐字回填，第 `j` 字（0-based）目标 x =
  `cx_{round(j·(K-1)/(L-1))}`（长度不符时沿栅格**插值**，保持原字节奏）；
  y = 行垂直中心 `y0 + (y1-y0)/2 - BAR_H`。
- **K<2（投影失败）**：回退整行均布 `x = x0 + (j+0.5)/L·(x1-x0)`。
- 纵向：每行 y 锚定到原 `y0`（见 §2），消除漂移。
- 字号：沿用 `_fit_font_size(line_txt, max_w=行宽, ...)`，长译文自动缩字号防溢出小框/行宽。

逐字用 `canvas.create_text(x, y, text=ch, font=(FONT_FAMILY,fs), fill=fg, anchor="center")`。

## 5. 回退与局限（第一性声明）

- **回退链**：投影失败 / 无 `line_boxes`（剪贴板、结构化模式）→ 整行均布或单块居中。
- **不在本期范围**：竖排文本（需纵向投影）、多栏/表格（需 layout 模型先分栏）、
  英文按词而非按字符断行（v1 按字符，CJK 无影响；拉丁长句可能跨词，后续可加词边界保护）。
- **依赖**：需把 `_kick` 抓取的源图 `img` 传入 `_render`（增加 1 个可选参数 `img=None`，
  旧调用方/测试不受影响）。

## 6. 风险

| 风险 | 缓解 |
|---|---|
| Canvas 重画后旧内容残留 | 每次 `_render` 先 `canvas.delete("all")` |
| 源图缺失（缓存命中路径）导致无法投影 | `img=None` 时回退整行均布 |
| 投影阈值对低对比/艺术字误切 | 阈值取相对值 + 失败回退；tiny 档已过滤鬼字 |
| 长译文溢出小框 | `_fit_font_size` 受行宽约束；仍溢出则 Canvas 裁剪（不撑爆窗口） |
| 测试契约破坏 | poll 测试已 mock `_render`；拖拽测试仅用 `_tran` 作事件 widget，改名 `_cv` 同步 4 处 |

## 7. 验收标准

1. 框选横排单栏图文 → 译文逐行钉在**原行 y**（与原文重叠，不再整体下移漂移）。
2. 译文逐字落点大致跟随原字符栅格（点阵小框质感），长/短译文均不溢出、不巨大。
3. 拖拽移动、随拖开关、Ctrl+Shift+N、方向切换、缓存、silent 行为**不变**。
4. 纯函数单测覆盖：水平投影切小框、回填映射（长度相符/不符插值、回退）。
5. 回归：字号 7 + 拖拽 5 + 轮询 5 = **17/17 全绿**（新增投影/回填纯函数测试另计）。
