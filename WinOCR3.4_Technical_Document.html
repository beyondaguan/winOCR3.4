1. 项目概述

WinOCR 3.4 是一款插件化的 Windows 桌面工具，集截图 OCR 识别、离线神经翻译、AI 对话解读于一体。采用纯 Python + Tkinter 构建，无需第三方 GUI 框架，支持绿色免安装运行。

核心能力

截图 OCR · 剪贴板 OCR · 划词翻译 · AI 解读 · TTS 朗读 · 知识库

架构特色

六轴插件化（capture/ocr/translate/ai/attach/persistence）+ 组合根 + 事件总线

目标用户

需要频繁进行屏幕取词、文献翻译、文本处理的 Windows 用户

分发方式

PyInstaller onedir 双 exe（GUI + CLI），绿色免安装

2. 系统架构设计

2.1 六轴插件化架构总览

系统采用分层架构，严格遵循依赖方向铁律：core 不依赖 services，services 不依赖 ui。各轴通过抽象基类定义契约，插件注册表自动发现并装配。

图 1：WinOCR 3.4 系统架构图

2.2 分层职责说明

层级 职责 核心组件 依赖约束
UI 层 用户交互、结果展示、事件绑定 MainWindow, MaskOverlay, ChatPanel, Tray 仅依赖 Services 层
Services 层 六轴业务逻辑、AI/OCR/翻译引擎 Capture/OCR/Translate/AI/Attach/Persist 仅依赖 Core 层
Core 层 组合根、配置、事件、管线、注册表 App, Config, EventBus, Pipeline, Registry 不依赖任何其他层

3.3 交互状态设计

状态 视觉表现 用户操作

5. 技术选型原则

维度 当前选择 选型理由
GUI 框架 Tkinter Python 标准库、零额外依赖、绿色分发、跨平台
OCR 引擎 RapidOCR + ONNX 中文准确率高、推理快、模型小（tiny 6.9MB）
翻译引擎 Argos (本地) + GLM (云) 离线优先保障隐私、云端兜底保障质量
AI 协议 OpenAI 兼容 统一接口、支持多提供商、可本地 llama.cpp
配置格式 TOML 人类可读、支持注释、类型安全（dataclass 解析）
打包方案 PyInstaller onedir 绿色免安装、启动快、依赖全打包
